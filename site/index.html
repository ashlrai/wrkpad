One grammar, three operating planes

Useful across the tools you already run.

The guarded Dual Plane profile keeps Codex Native on firmware layer 1 and gives Codex, Claude Code, cmux, and Fleet one provider-neutral workflow on layer 2. An opt-in Hybrid Native source experiment instead splits layer 1: six Codex-only Agent keys plus fourteen Agent Board shortcuts. Neither profile is imported or physically accepted by source tests.

Native when it should be.

First-run commissioning

Connected is the start—not proof that a key works.

Prove transport, layer, permission, input, assignment, and visible navigation in order. These steps configure nothing automatically and keep destructive recovery out of the normal path.
Official Codex Micro guideWork Louder setupFull wrkpad handoff
  1. 1Power + dataTurn on the Pro model and use a data-capable USB-C cable.
  2. 2Choose white wired modeHold the bottom-left touch control for three seconds, then tap until the underglow is white. A cable can charge while Bluetooth is still selected.
  3. 3Establish layer 1—do not guessA short touch advances the layer; it does not select layer 1. Treat only the expected visible response from a harmless assigned Codex Agent Key as evidence that native layer 1 is active.
  4. 4Check Settings, then restartConfirm Connected and Input Monitoring Granted. If permission or the layer changed, quit and reopen ChatGPT. Those indicators still do not prove key routing.
  5. 5Prove a visible actionFrom a normal task, double-tap a different assigned Agent Key within 350 ms. It should select that task and bring ChatGPT forward; one tap can switch without foregrounding.
  6. 6Recover without wipingQuit Karabiner or Logitech Options+ if it has Input Monitoring, reconnect, and run the read-only doctor. Do not use Input's Reset settings unless profiles are backed up and deletion is intentional.

Build from source

Core observer and desktop board.

No account or hosted control plane is required. These commands build both local components; hardware setup remains a separate acceptance flow.
terminal
git clone https://github.com/ashlrai/wrkpad.git
cd wrkpad
cargo install --path . --locked --root "$HOME/.local"
~/.local/bin/wrkpad init
~/.local/bin/wrkpad doctor
~/.local/bin/wrkpad demo

cd app
npm ci
npm run doctor
npm test
npm run dev
