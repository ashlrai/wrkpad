# Roadmap

The roadmap is evidence-gated and ordered by reliable daily value.

## Now: dependable public foundation

- Publish a clean repository with license, community policy, support boundaries, and reproducible CI.
- Pin supported Node and macOS versions after testing them.
- Add signed/notarized release automation with provenance and rollback.
- Add fixture-driven compatibility tests for `wrkpad` and Ashlr Hub schema versions.
- Improve first-run diagnostics and tool-discovery explanations.
- Validate keyboard navigation, screen readers, contrast, zoom, and reduced motion on packaged builds.

## Next: stronger local integrations

- Add a versioned provider-adapter interface with capability negotiation.
- Use verified Codex app-server capabilities for richer identity where supported.
- Correlate Claude Code sessions with cmux panes only when cmux exposes a stable, permissioned locator.
- Add user-controlled slot pinning and overflow without exposing raw session IDs.
- Add a secret-free setup exporter/importer.
- Add menu-bar presence and clear observer-health notifications.

## Later: qualified hardware feedback

Before physical lighting can be enabled:

1. Identify the exact USB/HID tuple and firmware.
2. Test read-only descriptors on supported hardware.
3. Prove ownership and coexistence with Input, ChatGPT, and HID software.
4. Implement an opt-in, reversible, rate-limited transport with fail-dark recovery.
5. Validate the black-opaque palette on real boards.
6. Keep the on-screen text/icon legend authoritative.

RGB must never be inferred from USB presence or shortcut Flight Check.

## Fleet and team operations

- Add a provider-neutral local event contract for more runtimes.
- Show provenance and freshness for every Fleet blocker and next action.
- Deep-link into read-only Ashlr evidence only when local targets are stable.
- Add team policy packs for common state language and safety tiers.
- Keep proposal decisions, permission approval, protected delivery, deployment, spending, and credentials outside one-press controls.

## Explicit non-goals

- Replacing Codex, Claude Code, cmux, Work Louder Input, or Ashlr Hub
- Bypassing native provider approvals
- Sending prompts or terminal input when a slot is selected
- Claiming exact focus without a verified locator
- Treating colors or dashboard counts as proof of execution
- Turning a macro pad into unreviewed release or infrastructure authority

An item becomes supported only with a defined failure contract, privacy and authority review, tests, packaged-build verification, current docs, real hardware/provider acceptance where relevant, and rollback.
